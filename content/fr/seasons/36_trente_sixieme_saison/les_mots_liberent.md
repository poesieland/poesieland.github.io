Les mots libèrent,

Parfois pas crus,

Les mots pubères,

Ivres et crus...

 \
Les mots plus graves,

Les mots liés,

Les mots se gravent,

Pas oubliés.

 \
Les mots plastiques,

Les mots donnés,

Les mots mystiques,

Mots pardonnés.

 \
Les mots qu'on lance,

D'oiseaux des noms,

Les mots balancent :

Mais... oui... mais... non.

 \
Les mots sensibles

Frappent au coeur,

Les mots sont cibles,

Un mot moqueur.

 \
Les mots s'enivrent

De vérité,

Les mots se livrent,

Félicité.
